# CreativeLab - Creative Guide

## Purpose
CreativeLab is not just a tool—it’s a **creative playground**.  
It helps users explore imagination through text, music, and art.

## How to Use
- **Text**: Generate stories, poems, dialogues, and jokes.
- **Music**: Create melodies, rhythms, chord progressions, and export to MIDI.
- **Art**: Produce ASCII art, fractals, and generative patterns.
- **AI Layer**: Enhance responses with context, sentiment, and style transfer.
- **Productivity**: Track ideas, plan projects, and set reminders.
- **Integrations**: Connect to external APIs for lyrics, art galleries, and sound libraries.

## Example Workflow
1. User asks: *“Write me a poem about coding.”*  
   → `poem_generator.py` produces a creative poem.  
2. User asks: *“Generate a melody in C major.”*  
   → `melody_generator.py` outputs notes, `midi_exporter.py` saves as MIDI.  
3. User asks: *“Make ASCII art of a tree.”*  
   → `ascii_art.py` generates a text-based tree.  

## Vision
CreativeLab aims to be the **largest open creative AI suite**, blending imagination with technology.
